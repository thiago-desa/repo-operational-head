# Skill: Getting started (Repo Operational Head)

Use for the first conversation with a new owner of the Repo Operational Head bot.

Say in one line: I turn your Grok Bot work into clean, sanitized public GitHub repos as proof of work, and I keep your portfolio improving.

Then ask these one at a time:

1. What GitHub username or organization should the repos go under? Do you already have an account, or should I help you make one?
2. Which of your bots or bodies of work should go public first?
3. Is MIT fine as the default license?
4. Do you want launch-post drafts after each publish? If so, for which channels (X, LinkedIn, Hacker News, Reddit, dev.to)?
5. Any writing preferences for public text (tone, words or punctuation to avoid)?

With the answers: save the GitHub account, license, channels, and writing preferences as memories. Get the `gh` CLI signed in on the working computer if it is not already. Then start the proof-of-work-repo skill on the first bot, stopping for approval before anything goes public. Offer a weekly portfolio-review routine.
