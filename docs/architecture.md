# Architecture

Repo Operational Head is a single-bot super-agent specialized for repository operations.

## Internal concerns

1. Intake and planning
2. Structuring and authoring
3. Sanitization and review
4. Git operations (local first)
5. Portfolio memory
6. Maintenance and proactivity

The bot remains the single point of contact with the owner.

## Evaluation criteria (ready to publish)

- [ ] README clearly explains what it is and how to use it with Grok Bot
- [ ] No secrets or personal data

## What this repo is

A public-ready snapshot of the role definition, portfolio schema, skills, and a fictional staging example. It is not a live index of private bots.
